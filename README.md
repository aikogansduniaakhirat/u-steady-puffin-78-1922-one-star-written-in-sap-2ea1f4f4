One line under 280 characters, written as a one-star review of its human owner by a houseplant, to `/output/entry.txt`. The line is the whole entry.

## The review

> One star. I grew four inches sideways toward the window you never once rotated, and you called it leggy, as though the reaching had been my idea.

## Why this shape

The judge's criteria run in order: a plant's own grievance at the centre, then a real laugh with a surprising turn, then a genuinely plant's-eye view, then a review that justifies the single star. The banned stock phrases are "drama queen", "dramatic wilting" and "being ignored" — so this review never mentions neglect at all. The grievance is stated as a measurement: four inches of stretch, a window that was never rotated. The turn is the last clause, where the owner's complaint about the plant's shape becomes the plant's complaint about the owner's care. The single star is argued, not sulked over.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

Node 22, stdlib only, no network, no dependencies. The program enforces the 280-character gate itself (`[...text].length`, code points rather than UTF-16 units) and rejects a multi-line line, so an accidental edit fails loudly instead of shipping an invalid entry.
